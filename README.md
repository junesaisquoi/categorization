# Carhartt WIP Web DMD

Shared Codex plugin for the Carhartt WIP Web Digital Merchandising & Data team.

## Skills

- `begin-web-dmd-workflow`: clickable workflow selector
- `category-builder`: commercetools category assignment from PIM data
- `campaign-product-picker`: campaign assortment curation and import prep

## Install

1. Clone this repo.
2. Add the repo folder as a local plugin in Codex (the manifest is `.codex-plugin/plugin.json`).

## Notes

- Do not commit catalog exports, credentials, or SharePoint files. See `.gitignore`.
- Version history is in `CHANGELOG.md`.
